- Retain the numeric grammar, including Sunday `0` only, leading zeroes, duplicate unions and steps on wildcards/ranges. Validation remains syntax-only.
- Use OR for two non-leading-star day tokens; otherwise intersect their membership sets. Lists retain token order when selecting the wildcard flag.
- Existing expressions use corrected semantics only on recomputation. There is no migration, legacy AND mode, replay, counter reset or lifetime extension.
- Preserve public helper signatures, `parseInterval` return shape, schemas, journal/store formats, fire caps, read-only metadata and loop limits. The trigger description alone changes.
