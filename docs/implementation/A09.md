## Contract coverage and limits

The all-fields test compares the whole saved entry, including iteration, awaiting-update flag, next wake, fire count, cap, expiry, trigger, read-only flag and recurrence. The checkpoint timestamp, entry timestamp and administrative pause timestamp all match. One captured callback sees only the final paused checkpoint. Single-field, omitted-field, empty-string and Unicode/multiline cases exercise exact merge semantics, including different old prompt and goal. Registered TypeBox schema checks reject null, numbers and objects; direct adapter calls are not presented as schema validation.

Snapshot callback rejection throws synchronously and restores the old memory snapshot before trigger removal or audit append. A later supplementary audit failure leaves the full pause committed and restorable. Shared-file reopening proves the checkpoint survives; an injected mirror failure proves an error can follow a committed rename. Separate status, iteration and timestamp conflicts exercise locked file reload and tool rejection without checkpoint mutation, trigger removal or accepted audit.

Session tests restore without update history and with a conflicting later audit record. They read all entries while the mocked current branch is empty. Restored paused loops do not fire during start, turn-start or settled pumping. Explicit command Resume dispatches one wake whose dynamic event data and rendered message contain every new marker and no old marker. Shared files override stale session mirrors. Legacy imports retain only saved values, including absent optional metrics and done criteria. Memory scope and a different session do not inherit the snapshot.

Other tests retain completion deletion, continue validation/omission rules, generic administrative pause, workflow/orchestration rejection and final-cap/deadline resume rejection. A09 leaves awaiting-update and next-wake fields unchanged on pause. A08 must incorporate this merge into its token-checked transaction and adapt fixtures to admitted wakes without weakening these assertions.

Live verification was omitted: A09 makes it optional when real-extension restoration and notification tests pass. There were no live pane launches. Session append success is not power-loss durability; shared-file and Pi audit writes are not a distributed transaction. Historical lost checkpoints are not reconstructed. Queued historical notifications are not rewritten. Passing unrelated defect characterizations does not establish their resolution or exhaustive regression freedom.
